# Cloud Engineering Portfolio

Vite + React frontend for the resume site.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Environment

Create a local `.env` file if you want to override the visitor counter API:

```bash
VITE_API_URL="https://your-api-url"
```

## Deployment

This app builds to `dist/`, which can then be uploaded to the static hosting bucket behind CloudFront.
